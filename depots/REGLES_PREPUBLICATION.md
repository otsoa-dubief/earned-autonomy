# Règles de prépublication lues le 18/11/2026 (préparation de T43 bis)

## OSF Preprints

Sources : https://help.osf.io/article/376-preprints-home-page ; https://help.osf.io/article/691-preprint-moderation-policies ; https://help.osf.io/article/727-osf-projects-transition (lues le 18/11/2026).

- Pré-modération : le dépôt reste privé jusqu'à l'acceptation ou au refus par un modérateur ; DOI à l'acceptation ; refus motivé ; un dépôt accepté ne se supprime pas (retrait seulement, avec page de retrait).
- **Politique de modération** : « Content completely or mostly generated by large language model (LLM) tools or other artificial intelligence (AI) tools is not appropriate for OSF Preprints. »
- Formulaire : titre, résumé, fichier (PDF conseillé), licence (CC BY 4.0 conseillée), sujets, mots-clés ; « assertions » : conflit d'intérêts (Oui/Non ; « Non » vaut déclaration d'absence), données publiques (liens), préenregistrement public (liens ; « Unavailable » si sous embargo) ; compléments : rattacher un projet OSF existant.
- Transition d'OSF : depuis le 16/11/2026, plus de nouveaux projets ; projets en lecture seule au 19/02/2027 ; prépublications et enregistrements non touchés. Le projet bd4g5 existe déjà.
- Versions : chaque nouvelle version acceptée a son propre DOI.

## arXiv

Source : https://info.arxiv.org/help/moderation/index.html (lue le 18/11/2026). Usage d'outils d'IA générative permis s'il est déclaré dans l'article ; l'outil n'est pas auteur ; l'auteur porte la responsabilité de tout le contenu. L'article le déclare déjà (« Use of AI tools »).

## Zenodo

Source : https://about.zenodo.org/policies/ (lue le 18/11/2026). Aucune règle sur le contenu produit par IA ; contenu de recherche à tout stade accepté ; pas de modération préalable ; DOI immédiat. Déjà utilisé pour les résultats (24321214).
